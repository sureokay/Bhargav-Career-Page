Spot the 3 Differences

Works fully offline in your browser. No API key, no server, free to host anywhere.

1. Generate a new puzzle + answer

Draws a random scene, changes 3 things, and circles them in the answer image. The answers are always correct because the code made the changes.

2. Mark answers on your own puzzle image

Upload a puzzle made anywhere (e.g. by an AI image tool). Either one image with the original on the left and the changed copy on the right, or two files (original first, then changed). The app compares them and circles the differences on the right side.
